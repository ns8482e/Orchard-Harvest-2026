## Orchard Core for Enterprise Systems — reading guide


**Gist:** A practical overview of using Orchard Core as a modular application framework for enterprise data, APIs, integrations, workflows and multi-tenant systems.

### Key takeaways

- Orchard Core extends beyond CMS use cases into enterprise application development. — slide 7, “Not just a CMS. An application framework.”
- Content items provide a JSON document model with targeted YesSql indexes. — slide 10, “Data: content items are documents”
- The deck covers resilient integration contracts, durable workflows and external identity. — slides 13–14, “Integrating a system you do not control” and “Workflows: push data where it needs to go”
- A real Azure architecture illustrates shared and dedicated multi-tenant deployment patterns. — slide 16, “The Infrastructure We Built”
